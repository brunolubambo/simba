SIMBA · assistente pessoal

Política de Privacidade

Atualizada em 30 de setembro de 2026

O SIMBA é um assistente pessoal de uso privado, operado por Bruno Lubambo. Ele só pode ser usado por quem tem o código de acesso e não é oferecido ao público.

Dados do Google que o SIMBA acessa

Somente depois que o titular da conta autoriza, e apenas para cumprir os pedidos dele:

  • Gmail: ler, pesquisar e organizar e-mails, criar rascunhos e enviar mensagens pedidas pelo usuário.
  • Google Agenda: consultar, criar e remover eventos.
  • Google Drive: pesquisar e ler arquivos (somente leitura).

Como os dados são usados e guardados

  • Os dados são usados só para executar o que o próprio usuário pede ao SIMBA.
  • As autorizações de acesso (tokens) ficam guardadas no servidor privado do SIMBA e não são compartilhadas com terceiros.
  • Para responder a um pedido, o trecho necessário é processado pelo modelo de IA Claude, da Anthropic.
  • Os dados não são vendidos, não são usados para publicidade e não são usados para treinar modelos de IA.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

A qualquer momento, em myaccount.google.com/permissions: escolha "Simba" e remova o acesso.
